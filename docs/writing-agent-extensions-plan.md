# 写作 Agent 扩展实施与验收

状态：扩展代码、作者端入口及工程回归已完成。最终一轮 48 项测试通过，作者端构建通过；真实付费模型的文学质量、外部 MCP 服务及浏览器交互仍需部署后验收。使用与部署见 [扩展说明](writing-agent-extensions.md)，测试证据见 [验证报告](evals/writing-agent/extensions-verification.json)。

## 交付范围

1. 样文上传／粘贴、异步分析、可编辑且待作者确认的文风档案。样文正文只进入分析通道，正常写作只加载结构化表达偏好，不加载样文人物与剧情。
2. 作者个人 Skill 编辑、修订、停用；MD／ZIP 导入预览后确认。规则版本与任务绑定，不执行脚本，不让文本授予工具或资料权限。
3. MCP Client：作者绑定作品的连接、加密 Bearer 令牌、初始化、发现和显式授权工具、任务选择、审计。支持 Streamable HTTP JSON／SSE，不启动外部程序；网络目标校验、固定解析 IP、TLS 主机校验、拒绝重定向。默认只接作者授权的只读工具；远端声明仍不构成安全保证。
4. 草稿分支与修订树、分支命名／比较／继续、历史版本选择，不丢失旧草稿。
5. 有界 Unicode Myers 差异与选区三方合并，独立修改可合并，重叠和重复目标要求作者解决；提交再次校验当前版本，撤销恢复合并前正文，不恢复过时基准。
6. 逐章摘要与累计摘要，保留来源版本／哈希／覆盖；前文修改使后续累计结果失效。调用付费模型需作品级开启。
7. 来源事务内持久事件，章节保存、状态或次序变化、删除后自动更新私有索引；按作品串行、租约／心跳／重试，向量化需开启并提示费用。
8. 删除传播：章节、作品、样文、Skill 删除后立即阻止读取，清理索引、摘要、相关候选、依赖任务快照、修订与采纳快照。保留无正文的删除账本；独立文件账本与备份恢复重放步骤一并交付，不承诺没有账本的任意旧备份能自动知道未来删除。

## 施工顺序

先完成来源事件与删除／更新，再完成资产、摘要与个人 Skill，随后接入分支合并、MCP 与作者端工作室，最后迁移与完整回归。所有修改保持现有接口兼容，不重启用户运行的 IDEA 服务，不修改锁定文件，不提交 Git，不调用真实付费供应商做开发测试。

## 验收

- 真实隔离 MySQL：触发器与源修改同事务提交／回滚、租约旧提交拒绝、身份隔离、重试和清理。
- 真 ES 或假客户端协议：关键词／向量只读取当前作者作品版本；删除和新版本不留可访问旧结果。
- 假模型：样文分析引文可定位、表达规则无样文剧情、章节／累计摘要来源完整、预算和失败不隐藏重试。
- Skill：无路径穿越或文件执行、ZIP 总量／数量受限、原 ID 不覆盖平台 Skill、作者确认与版本快照。
- MCP：本地假服务器验证握手、会话头、JSON／SSE、工具授权、失败与审计；真实网络调用另由作者配置后验证。
- 合并：随机差异回放、非重叠／重叠／重复文本／emoji／空选区、大改动降级、并发提交与撤销。
- 前端：工作室入口、样文／Skill／连接维护、同步开关与进度、分支和合并界面构建；未执行浏览器视觉验证不标通过。

官方 MCP 协议依据：[Streamable HTTP](https://modelcontextprotocol.io/specification/2025-11-25/basic/transports)、[Tools](https://modelcontextprotocol.io/specification/2025-11-25/server/tools)。
