小说管理系统 · 开发代理

四个前端应用收在同一个 origin 下的四个路径 —— 和生产的 Nginx 拓扑一致。
因为这个页面和下面四个应用同源，它们的 localStorage 才会真正共享。

📖 阅读端
/reader/ → localhost:5173
:5173
✍️ 创作中心
/author/ → localhost:5174
:5174
🛠️ 管理端
/admin/ → localhost:5175
:5175
📱 移动端（uni-app）
/mobile/ → localhost:5176
:5176
要验证多端免登录：从阅读端进入 → 点「模拟登录」→ 再点顶部导航跳到创作中心、管理端或移动端， 不需要重新登录。
注意：不要直接访问 localhost:5174 / localhost:5176 —— 那是另一个 origin，和这里不共享登录态，仅用于单独调试单个应用。
移动端建议：浏览器开发者工具切到手机视图（iPhone / 375px）再看 /mobile/，它按移动端布局设计，不是响应式缩放的桌面页面。
